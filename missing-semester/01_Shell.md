第一步是教 ```cd```

它可以讓我們在不同的資料夾之內遊蕩

```bash
cd /#回到最一開始的資料夾
cd .. #上一頁，相對位置
cd ~ #/home/kenri
cd . #這個資料夾
pwd #知道現在位置
ls #列出當前的檔案
```

其實還有很多的東西，但說老實話，因為我現在沒有需求，所以我學的沒有很起勁，但我相信這工具的確可以為我們省下許多時間，例如:

* 創建檔案
* 批量刪除檔案
* 找東西例如"error"
* 可以透過 ```|``` 來串聯不同的指令 一個做完接著做下一個
* 更甚者，可以把眾多的指令放在一個.sh的檔案內，下次要用時直接執行該檔案
